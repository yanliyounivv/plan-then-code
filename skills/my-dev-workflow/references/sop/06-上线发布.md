# 阶段⑥ 上线发布 SOP

## 准入（Entry）

- 验收通过，上线前清单逐项勾完。

## 固定动作（按顺序）

1. **跑 preflight 清单**：演示数据清理、初始密码修改、正式域名、环境变量生产值、定时任务等。
2. **等明确指令**：部署/发布/提审/开公网，一律等用户明确说，不擅自做。
3. **留回滚路径**：部署前确认回滚方案。
4. **上线记录留痕**：记录部署时间、版本、执行者、结果。

## 准出（DoD）

- [ ] 上线前清单逐项勾完
- [ ] 部署完成
- [ ] 回滚路径确认
- [ ] 上线记录留痕

## 上线前清单（逐条过）

- [ ] 演示数据、测试痕迹、假统计、假头像清理
- [ ] 默认账号密码已改
- [ ] 密钥齐全且不在前端/仓库/日志
- [ ] 占位符（域名/环境ID/包名/品牌名）替换
- [ ] 合法域名/白名单/编译配置正确
- [ ] 开发默认开关（免登录/mock/跳过校验）关闭
- [ ] 权限点与角色映射完整
- [ ] 前端调用路径已在后端路由注册
- [ ] 构建产物与源码一致
- [ ] 回滚方案可执行

## 收尾（文档在任务完成时统一更新）

- 上线的主产物是**部署完成的服务 + 回滚路径**，不是上线文档。
- **任务完成时**：部署时间/版本/结果在对话里汇报清楚并补记日志；需要留存操作手册时写 `docs/07-上线/`；文件结构有变才更新地图。

## 触发口令

| 用户说 | 动作 |
|---|---|
| "上线 / 部署" | 执行上线（必须用户明确说） |
| "别上公网 / 恢复上线前版本" | 完整回滚 + 停掉后台服务，并汇报停掉了什么 |
