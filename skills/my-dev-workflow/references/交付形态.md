# 交付形态决策表

> 交付形态服务于"把代码成果讲清楚"，不是归档流程。优先在对话里直接给结论/证据/截图；只有用户要长期留存时才落盘到 `docs/` 对应目录。

## 什么情况用什么呈现

| 情况 | 交付形态 | 落位 |
|---|---|---|
| 方案/设计/PRD | MD 文档 | `docs/02-方案/` |
| 重要技术决策 | ADR | `docs/02-方案/ADR/` |
| 数据看板/交互演示/原型 | 网页 HTML（单文件内联） | `docs/02-方案/` 或临时预览 |
| 表格数据/清单/台账 | 表格（MD 或 xlsx） | 对应目录 |
| UI 改动/界面效果 | 截图对比（改前/改后） | `docs/06-验收/` |
| 接口契约/表结构/状态机/字典 | MD 契约 | `docs/03-契约/` |
| 评审/审计结果 | MD 报告（分级） | `docs/05-审计/` |
| 状态机/流程/架构/时序图 | Mermaid | `docs/图/` |
| 过程记录 | 表格日志 | `docs/日志/` |
| 上线/部署/回滚 | MD 操作文档 | `docs/07-上线/` |

## 核心原则

- 能点/看的 → 网页
- 要审文字的 → MD
- 要对比的 → 截图
- 要查数的 → 表格
- 要表达流转的 → 图

## 网页交付要求

- 单文件 HTML，内联 CSS/JS/SVG，不引外部 CDN/字体，离线可开。
