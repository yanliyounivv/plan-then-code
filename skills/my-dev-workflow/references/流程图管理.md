# 流程图管理

## 统一位置

```
docs/图/
├── 状态机/     # 订单状态机、审核状态机、额度状态机...
├── 流程/       # 业务流程、上架流程、审核流程...
├── 架构/       # 系统架构、目录结构、数据流...
└── 时序/       # 关键链路时序图...
```

## 格式：默认 Mermaid

- 纯文本，可 git diff
- AI 可直接生成和读取
- 可渲染成图（网页/文档内显示）
- 不引入二进制，和 MD 体系一致

## 命名规范

`[类型]-[对象].mmd`，如：
- `状态机-订单流转.mmd`
- `流程-上架流程.mmd`
- `架构-系统架构.mmd`
- `时序-报价成交流程.mmd`

## 铁律

1. 图是**辅助表达的副产品**：确实需要表达流转关系时才画，不为凑文档画图；能一句话说清的就不画图。
2. 画了且要长期保留的图 → 进文件地图表（`docs/00-项目总览.md`），临时说明用的草图不必。
3. 保留的图要填「对应代码/契约」列绑定真实代码位置，防图漂移。
4. 改代码时只在**状态机/流程真的变了**才同步改图，别为"可能有漂移"逐张翻查。
5. 图改动了，文件地图的「版本」和「更新人」才更新。
