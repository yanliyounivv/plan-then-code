# 交付规范

> 定位：交付汇报结构、模板、自查清单的**唯一权威处**。铁律不在这里重复——`R14`（证据三选一）、`R15`（分级标注）、`R16`（等指令）见 `SKILL.md`。

## 交付汇报结构（全系统只此一处）

```
结论（能不能用 / 到哪一步 / 有无阻塞）
做了什么（按模块，标【真实现 / 占位 / 演示数据】）
证据（命令结果 / 接口输出 / 截图路径 / 云端日志）
已知问题与遗留（带原因和下一步）
等你决定的事（是否提交、是否上线、要不要继续做 X）
```

不贴大段原始日志；不夸大（没打通不写"已完成"，没验证不写"已验证"）；不甩锅环境（环境问题给判定依据与绕行方案）。

## 交付动作

- **日志**：`docs/日志/YYYY-MM-DD.md`（一天一个文件，口径见 `my-dev-workflow/references/日志规范.md`），字段用 `assets/日志模板.md`。
- **进度报告**：上线前给"已做 / 未做清单 + 进度百分比"，以代码为准。文档写完成但代码没有的，算未做。
- **验收链路**：重启三端 → 逐页点检（每页按钮都点）→ 截图 → 真机调试 → 加体验者给好友测。走到第几步、哪些没做，说清楚。
- **账号密码**：交付后台时给测试账号密码清单（含角色与权限范围），并提醒上线前改掉。
- **上线前清单**：完整清单在 `my-dev-workflow/references/sop/06-上线发布.md`，那是唯一权威源，此处不重复。

**汇报三段式**（长任务进行中）：已完成 / 进行中 / 卡在哪 + 下一步。细则见 `协作流程.md` §4。

## 检查清单

### 项目启动检查清单

- [ ] 已读项目 `AGENTS.md` / lint 与构建配置
- [ ] 已读真实代码，确认技术栈与目录边界（不信旧文档口径）
- [ ] 已确认既有决策（AppID/主体、是否上线、是否迁数据、支付是否做）
- [ ] 已复述理解、范围、方案与"不做项"
- [ ] 已列出 2~3 个方案或获得自决授权
- [ ] 已识别视图层、数据层、接口、权限、状态机影响面
- [ ] 已列出文件级变更清单和回滚方案
- [ ] 已确认是否涉及删除、发布、push、表结构或工作区外写入

### 契约对齐专项清单（历史 bug 全出在这）

- [ ] 详情页字段：timeline / product / seller / counterparty / canReview 真实返回
- [ ] 列表页字段：counterparty、source、时间字段（`createdAt` / `favoritedAt` / `viewedAt`）
- [ ] 图片字段名一致（`images` / `imageUrls` / `url`），新建与编辑走同一套
- [ ] 状态枚举前后端字符串一致，分类函数同步
- [ ] 金额分/元转换在每个出口都做
- [ ] 权限码前后端同一份常量
- [ ] 分页参数（page/pageSize/limit）后端真读
- [ ] 写操作有防重与幂等
- [ ] 未实现的能力明确占位并隐藏入口，不留"点了必失败"的页面

### 迁移 / 复刻验收清单

- [ ] 视图层（wxml/wxss/json/组件/全局样式/资源）与原项目逐字节一致
- [ ] 差异只存在于数据层（请求、类型、适配、环境配置）并已列清单
- [ ] 渲染问题按 CSS 层叠/布局机制判断，未用"文件一致"当结论
- [ ] 契约三方对照做过，前端字段全部有后端来源
- [ ] 系统基础配置已 seed（字典/地区/角色/权限/管理员/配置/模板/开关）
- [ ] 编译产物已更新且与源码一致
- [ ] 三端主链路跑通，构建/类型检查全绿
- [ ] 旧代码归档 `archive/` 可对照，工作区无临时软链与嵌套目录

### 交付前自查清单（逐条过，不许跳）

**数据与契约**
- [ ] 没有假数据、假时间、假统计、假头像、前端兜底列表（`R10`）
- [ ] 每个按钮点下去都有真接口/真跳转/真写库（`R11`）
- [ ] 五方对齐：前端调用 ↔ 前端字段 ↔ 后端返回 ↔ 数据库 ↔ 后台操作（`R12`）
- [ ] 前端所有接口路径已在后端路由注册（做过差集）
- [ ] 状态枚举单一来源、全端一致、用户看到的全中文（`R13`）
- [ ] 金额单位、数量换算、日期格式统一

**流程与权限**
- [ ] 主链路能从入口走到完成再回来
- [ ] 不同角色看到并只能操作自己的按钮
- [ ] 前端禁用的操作后端也拒绝
- [ ] 权限点真实存在，后台按钮可见可用

**界面**
- [ ] 改完截图对比过（改前/改后）（`R14`）
- [ ] 文字无截断/重叠，留白均匀，按钮样式统一

- [ ] 无 emoji 当图标，无裸色值，图标语义贴切

**工程**
- [ ] 构建 / 类型检查 / 测试通过（贴输出）

- [ ] 服务后台驻留且端口可访问（若用户要求启动）

**交付物**

- [ ] 每项标注【真实现 / 占位 / 演示数据】（`R15`）

- [ ] 等用户决定提交 / 上线，没擅自动作（`R16`）
