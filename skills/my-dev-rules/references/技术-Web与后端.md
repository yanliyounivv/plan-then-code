# 技术红线：Web 管理后台 / Python 后端 / 本地服务

> 通用底线见 `技术-通用红线.md`，本篇只写这三类的专属坑。

## Vue / Web 管理后台

- 按钮权限对应的权限点必须**真实存在**于种子数据（历史：页面用 `finance:manage`，权限表只有 `finance:review`，审批按钮永不显示）。
- 前端每个调用路径都要在后端路由表注册；未注册 = 点击必 404。交付前做"前端 post/put 路径 vs 路由表"差集。
- 列表筛选/搜索/分页必须把 query 传到后端；后端忽略 query 会导致筛选无效、`total` 恒为全量。
- 后端以分存储时，后台列表/详情统一 `fenToYuan` 再返回，否则金额放大 100 倍。
- 权限码前后端同一份常量（历史：菜单用 `risk:view`、接口要 `system:config`，菜单可见但保存 401）。
- 选中行、悬停、弹窗宽度、表单列数全站统一；大表单不要靠纵向滚动。
- 图表/地图用真实接口数据，空数据给空状态，不画随机曲线。

## Python / FastAPI 后端

- 可选字符串字段的空字符串归一为 `None`（否则带 `pattern` 的手机号校验会把 `""` 判非法，导致"只填名称也存不了"）；前后端都归一，双保险。
- Schema/模型变更走迁移（Alembic），迁移可回滚，不手改生产表。
- 依赖固定版本、用 venv/uv 隔离；交付写清启动命令与端口。
- 接口错误统一包络（code/message/data/requestId）。
- 长任务不阻塞请求；外部调用加超时与重试上限。

## 本地工具 / 桌面端服务 / 后端进程

- 服务启动后必须验证端口与健康检查，别只说"已启动"；进程要后台驻留，不能随 shell 退出。
- 改配置、改环境变量后要重启服务并复测，不假设热加载生效。
- 外部命令调用：先并发读取 stdout/stderr，再 `waitUntilExit`，否则大输出会死锁卡死。
- 多线程读共享数据用主线程快照；单例并发警告用显式标注（如 `nonisolated(unsafe)`）解决，不靠改语言版本掩盖。
- 外部命令输出按字节容错解码，别让一个非 UTF-8 字符丢掉整行。
- 常驻程序要处理唤醒重连失败，静默降级提示；同类错误弹窗去抖，不轰炸。
