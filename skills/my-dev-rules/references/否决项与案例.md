## 用户喜欢 / 常提的要求（主动照做，别等催）

- 品牌统一：logo、名称、主题色调全套一致。
- 数据可视化：后台要地图/图表等可视化，不要只有表格。
- 图标语义：入口图标要贴切，图标缺失/不显示是 bug。
- 角标与已读：消息角标数量要真实，"全部已读"入口要有。
- 搜索：搜索历史/热门搜索/排行榜都要真实后端；结果页直接展示结果。
- 筛选：筛选条件以胶囊形式显示在结果区上方，可点叉移除并实时联动。
- 排序：点价格出排序面板（抽屉），支持业务维度。
- 审计报告按严重度排序（致命/高/中/低），每条带 文件:行号 证据。
- 多视角评审：重要 UI 改版前给多个风格方案对比。
- 高频验收动作：重启三端 → 逐页点检 → 截图 → 真机调试 → 加体验者测。
- 证据分级：区分"已查证"与"假设"，标注来源与置信等级（用户惯用 E1/E2/E3），矛盾点单独说明。
- 单文件交付：网页/报告类产物默认离线可运行单文件，不引外部 CDN。
- 纯净产出：去掉聊天记录、版本流水等噪音，只留结论、数据、来源。
- 迁移/复刻：界面要和之前"一模一样"，只改数据层。
- 每页都要点一遍。
- 能自动识别/自动带出的输入别让用户手填；能少一个字段就少一个。
