# 技术红线：微信小程序 + 云开发

> 通用底线（契约/校验/并发/金额/验证闭环）见 `技术-通用红线.md`，本篇只写这两个端的专属坑。

## 微信小程序

- **WXML 里绝不能调 JS 函数**（含 `join()`/`indexOf()`/`slice()`/`map()`），WXS 也别依赖。展示串在 JS/model 层预生成（`priceFmt`、`benefitsText`、`timeText`），WXML 只做 `{{字段}}`。
- **t-icon 图标名只能字母数字连字符**，下划线会被过滤不渲染；先查 iconfont 确认存在。
- tabBar 页跳转必须 `wx.switchTab`；自定义 tabBar 别开 `lazyCodeLoading: requiredComponents`。
- 相对路径 `../` 层数容易错；页面 wxss 不写 `page{}`；app.json 注册页四文件齐全；`navigationBarTitleText` 迁移时最容易丢。
- **ESM/CJS 禁止混用**：utils、node_modules 产物统一模块体系（tdesign dist 是 ESM，需 tsc 转 CommonJS），否则编译报 `Unexpected token 'export'`。
- 用 npm 组件库（TDesign 等）必须先"构建 npm"；**但零 npm 依赖的项目点"工具→构建 npm"必然报 `NPM packages not found`——这是正常提示，不是 bug**，直接编译/预览即可。
- TS 工程若预编译 JS 产物入库，`useCompilerPlugins` 要关掉（否则 GUI 会去找 typescript 包并报 NPM 错）；CLI 与 GUI 走不同编译链路，CLI 出包成功不代表 GUI 无错。
- 本地开发在开发者工具勾选"不校验合法域名"，否则演示图片/局域网接口全被拦。
- 环境版本锁稳定版基础库；`packOptions.ignore` 排除 admin/node_modules 等非小程序目录。
- 返回后要刷新数据的列表，`load()` 挂 `onShow` 而不是只有 `onLoad`。
- 云函数时间统一 `nowStr()` 校 UTC+8。

## 云开发（CloudBase）

- 私有读必须 `getTempFileURL` 签名；fileID 漏桶名必报错。
- **单次 get 默认 20 条（云函数 100）**：`findMany` 式写法会静默截断，必须分页 `fetchAll`。
- 无 Decimal → 金额整数分；无跨集合事务 → 乐观状态机 `where({_id, status: _.in(from)}).update()` 看 `stats.updated`，0 行抛 409；无自增主键 → Sequence + `cmd().inc()`。
- **无进程内存**：验证码、refresh 记录、失败计数必须外置到带 TTL 的集合，否则多实例/冷启动必失效。
- 查询正则用 `db.RegExp({regexp, options})`，不是 `$regex`。
- **数据库初始化必须用云函数内的 `wx-server-sdk` 执行**（init-db）：`tcb db nosql execute` 与云函数访问的可能不是同一个库，只看 CLI 侧 count 会得到"已初始化"假象；建完必须在云函数运行日志里验证。
- 集合清单要和代码 `col()` 调用定期对比（漏过 `Sequence`/`CaptchaStore`/`ApprovalFlow`）；先建集合+索引再读写。
- 云函数默认 3s 超时：初始化重活要支持分批（collections/indexes/seed + from/to 切片）；CLI 首次部署有 "Creating" 竞态，等约 30s 重试。
- N+1 红线：批量场景收集 ids → 一次 `in` 查询 → 内存 Map 组装。禁止 `for...of await` 逐条查库。
- 图片只用云存储 fileID，不入库公网外链（必裂图）；上传失败不得静默用本地临时路径入库。
- 前端只经 services/request 层调云端，页面里不散写 `wx.cloud.callFunction` / `wx.request`（验收：`grep wx.request` 只剩请求层一处）。
- **HTTP 模式切 `callFunction` 时 header 不归一**：鉴权头要显式匹配后端读取的键名（同时带 `x-auth-token` 与小写 `authorization`）；未授权码统一成 401，否则前端重登逻辑失效。
