# 我的开发规范（my-dev-rules）

用户本人的开发协作铁律与审美偏好，从 600+ 条真实协作对话与 5 个本地项目提炼。**接到开发类任务先读本文件；违反编号铁律等于返工。**

触发：写代码 / 改 UI·样式·文案 / 技术方案与选型 / 审计代码·排查 bug·真机异常 / 迁移·复刻·重构 / 验收交付前核对。
不触发：纯问答、翻译、闲聊；**推进节奏、排期、先出计划**归 `my-dev-workflow`。

## 规则优先级（冲突时按此裁决，全系统唯一一处定义）

| 级别 | 内容 |
|---|---|
| P0 | 用户在**本次对话**里的明确指令（覆盖本文件任何条款） |
| P1 | 安全与数据不可逆风险——宁可停手先问 |
| P2 | 编号铁律 `R01`–`R16` |
| P3 | 流程阶段顺序（`my-dev-workflow` 的 `W01`–`W05`） |
| P4 | 技术细则（`references/技术-*.md`） |
| P5 | 案例库与历史经验 |

**三条元规则**（跨级或同级冲突都按这个判）：

1. **两个 skill 打架**：先判是「顺序」还是「质量」问题——顺序听 workflow，质量听 rules；分不清取更保守的一方。
2. **规则与磁盘代码/实测冲突**：当轮以实测为准，按真实代码办事，收尾回头改规则并记进化日志。**规则不许压过事实。**
3. **同级冲突**：先看是否触及不可逆伤害（是则 P1 优先）；再比范围——`R03 修一处扫同类` ≠ 全改：**扫出来必须一次汇报，但只修「本任务范围内」+「影响当前链路的」，跨模块的列清单等用户拍板**，不拿"扫同类"当扩需求的理由。

## 十六条铁律（违反即返工，可在日志/审计里回指）

| 编号 | 铁律 | 判定 |
|---|---|---|
| R01 | 不许没理解就动手 | 模糊指令先复述理解，等确认再动手 |
| R02 | 不许只看文档不看代码 | 审计/进度/排查只认磁盘代码与实测 |
| R03 | 不许修一处不查同类 | 修完全项目扫同类，一次汇报一起修 |
| R04 | 不许重复索要已给信息 | 参数、截图、报错不再问第二遍 |
| R05 | 不许原地空想不行动 | 缺插件缺方案就自己去找去试 |
| R06 | 不许把占位当真实现 | 占位说占位，假数据说假数据 |
| R07 | 不许把环境噪音当缺陷 | 先判性质，不为误报改业务代码 |
| R08 | 不许启动完不验证 | 端口+健康检查+主链路；验不了要说验不了 |
| R09 | 不许拿"文件一致"当结论 | md5 相同 ≠ 渲染正确，查 CSS 层叠 |
| R10 | 无假数据 | 数据须入库、走真实链路；空就展示空状态 |
| R11 | 无死按钮、无断流程 | 按钮真调接口；发起→详情→流转→完成→可回看 |
| R12 | 前后端契约一致 | 调用↔字段↔返回↔库↔后台，五方对齐 |
| R13 | 状态全中文 + 全端共用 | 一张枚举映射表，不把 pending 透给用户 |
| R14 | 证据三选一必给 | 接口实测/构建通过/截图；UI 必须前后对比 |
| R15 | 功能分级标注 | 【真实现/占位/演示数据】，占位要留扩展点 |
| R16 | 部署提交等指令 | 部署、提审、开公网、重启、git 提交都等明确说 |

> `R01`–`R09` 的真实案例见 `references/最痛的教训.md`；`R10`–`R13` 细则见 `references/产品体验.md` §4–§7；`R14`–`R16` 的结构与清单见 `references/交付规范.md`。

## 边界与越界（能力黑名单）

**不做**：纯问答/翻译/闲聊 · 计划排期与人力估算（→ `my-dev-workflow`）· 代替用户决定涉钱/资质/合规/发布的事 · **没看到代码就给架构评审结论**。

越界时两句话之一：**「这归 X 管」** / **「要先看到代码（或截图、报错原文）才能判断」**——不硬接、不编、不用通用知识蒙。

## 技术选型（动态，不写死结论）

**先查当下最优**（联网、附来源与时间）→ **按"个人开发者 + B 端小流量"收敛**（运维成本优先）→ **给 2~3 候选让用户拍板**。方法论见 `references/协作流程.md` §7。
单文件交付物内联 CSS/JS/SVG，不引外部 CDN/字体——交付形态要求，与选型无关。

## 使用方式

1. 在触发域内 → 生效。**「规则优先级」+「十六条铁律」每次必读**，references 按需 1–2 篇。
2. 交付前过 `references/交付规范.md` 的「交付前自查清单」；收尾按 `W04` 补齐日志/地图/契约/流程图/ADR。
